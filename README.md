# 🎨 illustration_concept

An experimental prototype for an online illustration shop, built using **React**, **Vite**, and basic **web scraping techniques** to fetch content from Instagram.

> 📌 Project Goal: To explore the process of turning an illustrator’s Instagram portfolio into a web-based gallery or e-commerce platform.

---

## 🧠 Motivation

This project was inspired by the work of a close friend and illustrator. I wanted to build a proof-of-concept web shop that automatically pulls artwork from their Instagram and presents it in a responsive, gallery-style frontend.

It's a work-in-progress, but it touches on several interesting areas:
- Automation via scraping
- Image handling & layout
- React component design
- Static content presentation

---

## 🚀 Features

- 📷 **Scraped illustration content** from Instagram using simple web-scraping logic
- 🧱 **Component-based React UI** for clean, reusable layouts
- ⚡ **Vite development server** for fast iteration
- 🎨 Minimal styling to keep the focus on the artwork
